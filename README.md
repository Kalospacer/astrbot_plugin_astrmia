# AstrMia (`astrbot_plugin_astrmia`)

将 **I.R.M.I.A** 的「全局唯一主脑 + 手边三层未读信箱 + 群话题概括 + 群点名半遮面通知 + `read_channel` 防刷屏翻阅 + 5~60分钟连续概率呼吸心跳」引入 AstrBot，并复用 **AstrHe** 的聊天账本与关系本。

## 核心特性

1. **全局唯一主脑模式（Unified Master Brain）**
   - 所有私聊唤醒、群聊点名唤醒和呼吸心跳唤醒统一汇入同一个主对话流（`master_umo`），使她拥有跨群、跨私聊的连续短期上下文与全局视野。
   - 共享主脑的请求会在读取历史前排队，前一轮保存完历史后下一轮才开始，避免多个窗口同时改写同一份历史。排队只覆盖本插件管理的路径（各会话的普通对话与心跳/手动唤醒），AstrBot 原生定时任务等不经过插件钩子的路径不在其中。
   - 每个窗口的发送目标、用户身份（管理员/普通成员）与工作目录保持 AstrBot 原生规则不变。
2. **手边信箱与分流器（Inbox Router & Group Batcher）**
   - **私聊**：无条件直接唤醒，正文当场呈现。
   - **群聊普通消息（未 `@`、未引用回复、未提及称呼关键词）**：静默拦截归入信箱，不打断主脑，未读数 `+1`；达到未读门槛且超过冷却时间时后台异步调用轻量模型更新**话题概括**（默认 24 字以内，可在「话题概括」配置组调整）。冷却按上一次实际尝试时间计算，概括失败同样要等冷却结束。
   - **群聊点名消息（`@` / 引用回复 / 命中称呼关键词）**：经可选防大喘气攒批窗口合并后，将本轮输入替换为 **I.R.M.I.A 半遮面通知卡**（告知谁在哪儿叫了她、积了多少条未读、那边在聊什么话题），引导她先调 `read_channel` 看完前因后果再决定回不回。
3. **三层信箱简报与 `read_channel` 工具**
   - 每轮请求尾部临时注入 `【此刻层 · 状态与信箱清单】`（含活跃会话的 `sid`、最后时刻、未读条数与话题，不污染持久历史）。时间、信箱清单以及 AstrBot 本地运行时的工作目录说明都放在本轮用户消息末尾，system 前缀里只保留稳定的装置自述，减少不同窗口之间的前缀差异；实际缓存命中率取决于所用模型服务商。
   - `read_channel(sid, before, limit)`：支持跨会话读取任何群或私聊；内置 **5 分支防刷屏精选**（刷屏时默认只给提及她的行 + 前 10 条上下文）；合并 `（我）` 自己的历史发言防止重复发送；看过的推进已读水位线，带 `before` 游标往回翻页（每页 50 条）不修改已读。
4. **5~60 分钟连续概率呼吸心跳（Continuous Probability Heartbeat）**
   - 安静 `< floor`（默认 5 分钟）绝不触发；`floor ~ ceil`（默认 5~60 分钟）按 $p = q^\alpha$ 每个抽签间隔（默认 60 秒）抽签一次（通过 200 步二分法反解满足目标均值的 $\alpha$，默认参数下 $\alpha \approx 1.1032$）；达到 `ceil`（60 分钟）必然触发；私聊或群聊点名到达时立即归零。
   - 需要先绑定全局主脑会话才会运行；正在和人对话时本拍跳过。单拍出错只记日志，下一拍照常继续。
   - 心跳触发时使用静默事件唤醒主脑，她可自主决定翻信箱、调用 `send_message_to_user` 主动找人说话，或安静继续睡。
   - 本拍翻过信箱或调用过工具时，用轻量模型写一句小结（默认 60 字以内）追加进主脑上下文；小结失败则不写，空拍什么都不留。
5. **与 AstrHe 联动**
   - 自动检测并只读挂载 `astrbot_plugin_astrhe` 的 `astrhe.db`：直接复用其 `messages` 聊天账本（含 `is_bot=1` 主动发言与 `recalled=1` 撤回标记）与 `persons` 关系本别名；未安装 `AstrHe` 时自动回退内置 `fallback_messages` 表。
   - 自动识别并让路 `AstrHe` 的夜间复盘 `SilentNightEvent`。
   - 长期记忆由 `astrbot_plugin_livingmemory` 等插件按其自身设置处理，本插件不改变它们的会话隔离方式。
6. **说话出口与沉默权**
   - 默认：普通文字直接回复唤醒她的窗口；单独输出 `[SILENT]` 时这句不发出，但这一轮对话照常保存进主脑历史。
   - 可选开关 `intercept_direct_reply`（工具已发到当前窗口时收起末尾回复）：开启后，如果本轮已经用 `send_message_to_user` 成功发到了唤醒她的这个窗口，之后的普通文字只记日志、不重复发出；没发到这个窗口（或只发给了别的群/私聊）时，普通回复照常发出。
   - 心跳/手动唤醒时普通文字一律不发出，只能通过 `send_message_to_user` 找人说话。

## 管理员指令

- `/astrmia status`（或 `/irmia status`）：查看全局主脑绑定状态、AstrHe 联动状态、心跳分布参数（$\alpha$、已安静时长、下一拍命中概率）及外部会话未读信箱列表。
- `/astrmia wake [备注]`（或 `/irmia wake [备注]`）：手动触发一次全局主脑静默唤醒（未绑定主脑会话时会提示并跳过）。
