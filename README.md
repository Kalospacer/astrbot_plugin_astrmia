# astrbot_plugin_irmia

将 **I.R.M.I.A** 的「全局唯一主脑 + 手边三层未读信箱 + 24字群话题概括 + 群点名半遮面通知 + `read_channel` 防刷屏翻阅 + 5~60分钟连续概率呼吸心跳」完整引入 AstrBot，并与 **AstrHe**、**LivingMemory** 无缝联动。

## 核心特性

1. **全局唯一主脑模式（Unified Master Brain）**
   - 所有私聊唤醒、群聊点名唤醒和呼吸心跳唤醒统一汇入同一个主对话流（`master_umo`），使她拥有跨群、跨私聊的连续记忆与全局视野。
2. **手边信箱与分流器（Inbox Router & Group Batcher）**
   - **私聊**：无条件直接唤醒，正文当场呈现。
   - **群聊普通消息（未 `@`、未引用回复、未提及称呼关键词）**：静默拦截归入信箱，不打断主脑，未读数 `+1`；达到未读门槛时后台异步调用轻量模型更新 **24 字话题概括**。
   - **群聊点名消息（`@` / 引用回复 / 命中称呼关键词）**：经可选防大喘气攒批窗口合并后，将本轮输入替换为 **I.R.M.I.A 半遮面通知卡**（告知谁在哪儿叫了她、积了多少条未读、那边在聊什么话题），引导她先调 `read_channel` 看完前因后果再决定回不回。
3. **三层信箱简报与 `read_channel` 工具**
   - 每轮请求尾部临时注入 `【此刻层 · 状态与信箱清单】`（含所有活跃会话的 `sid`、最后时刻、未读条数与 24 字话题，不污染持久历史，保护前缀缓存）。
   - `read_channel(sid, before, limit)`：支持跨会话读取任何群或私聊；内置 **5 分支防刷屏精选**（刷屏时默认只给提及她的行 + 前 10 条上下文）；合并 `（我）` 自己的历史发言防止重复发送；看过的推进已读水位线，带 `before` 游标往回翻页（每页 50 条）不修改已读。
4. **5~60 分钟连续概率呼吸心跳（Continuous Probability Heartbeat）**
   - 安静 `< floor`（默认 5 分钟）绝不触发；`floor ~ ceil`（默认 5~60 分钟）按 $p = q^\alpha$ 每分钟抽签（启动时通过 200 步二分法精确反解满足目标均值 `15 分钟` 的 $\alpha \approx 1.1032$）；达到 `ceil`（60 分钟）必然触发；任何外部消息到达立即归零。
   - 心跳触发时使用静默事件唤醒主脑，她可自主决定翻信箱、调用 `send_message_to_user` 主动找人说话，或安静继续睡。
5. **与 AstrHe / LivingMemory 深度联动**
   - 自动检测并只读挂载 `astrbot_plugin_astrhe` 的 `astrhe.db`：直接复用其 `messages` 聊天账本（含 `is_bot=1` 主动发言与 `recalled=1` 撤回标记）与 `persons` 关系本别名；未安装 `AstrHe` 时自动回退内置 `fallback_messages` 表。
   - 自动识别并让路 `AstrHe` 的夜间复盘 `SilentNightEvent`。
   - 长期记忆交由 `astrbot_plugin_livingmemory` 处理。
6. **可选「屋里自言自语 vs 调工具对外说话」开关（`intercept_direct_reply`）**
   - 默认关闭（保留直出回复，输出 `[SILENT]` 可保持沉默）；开启后，模型直接输出的普通文字视为屋内自言自语（只记日志不发往 QQ），必须调用 `send_message_to_user` 才对外发声。

## 管理员指令

- `/irmia status`：查看全局主脑绑定状态、AstrHe 联动状态、心跳分布参数（$\alpha$、已安静时长、下一拍命中概率）及外部会话未读信箱列表。
- `/irmia wake [备注]`：手动触发一次全局主脑静默唤醒。
